# Agent instructions

## Repository guidance

- Follow the development guidelines in [GEMINI.md](GEMINI.md) for code style,
  architecture, testing, and the standalone web UI.
- Use [CONTRIBUTING.md](CONTRIBUTING.md) for development setup and the
  contribution process.
- Read the [testing guide](.agents/skills/run-tests/SKILL.md) before editing or
  debugging tests. Use the repository's `pnpm` scripts to run them.

## Before committing

Run `pnpm lint` from the repository root. It must pass before you commit.
